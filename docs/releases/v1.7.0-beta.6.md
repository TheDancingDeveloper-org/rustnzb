# rustnzb v1.7.0-beta.6

## Highlights

- **The connection pool updates on every refresh.** The pool panel now
  refreshes with the queue on every poll, with no 5-second hold, and
  `/api/status` reports two counts per server: `connected` (sockets that are
  open) and `active` (connections transferring right now).
- **History shows every row.** The History page defaulted to a 7-day window,
  so it could show "1–3 of 3" while the database held 1,730 entries. It now
  lists all History by default; the stat cards keep their 7-day window.
- **A flaky speed-limit test is fixed.** The speed-limit harness tests now
  wait on download progress instead of a 3-second wall-clock deadline, so a
  busy CI runner no longer fails them.

## Upgrade notes

- No database migrations in this release. Backing up `rustnzb.db` before
  upgrading is still recommended.

## All changes

### Fixed

- **status:** `/api/status` reports open (`connected`) and transferring
  (`active`) connections, and the GUI pool updates on every refresh (WI-2086)
- **ui:** History lists all rows by default; stat cards keep the 7-day window
  (WI-2139)
