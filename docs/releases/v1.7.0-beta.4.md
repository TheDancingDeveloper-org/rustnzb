# rustnzb v1.7.0-beta.4

## Highlights

- **Downloads no longer fetch every PAR2 recovery volume up front.** A job
  fetches only the recovery data it needs once damage is actually found, plus
  a small margin, so healthy downloads transfer far less data. Set
  `[par2] defer_volumes = false` if you would rather fetch everything eagerly.
- **Repair works from data already in flight.** PAR2 slices are verified as
  they arrive, and when damage is found the repair is solved from those
  verified slices instead of re-reading the files from disk. Post-processing
  still falls back to a disk-based repair when the in-flight data cannot
  cover the damage.
- **Hopeless jobs are judged by parity, not by guesswork.** A job is only
  declared unrecoverable when the damaged slices genuinely exceed the
  recovery slices available, so jobs that would have repaired successfully are
  no longer abandoned early.
- **History is much faster.** List columns are read from a side table instead
  of past the stored NZB, statistics and counts are aggregated in SQLite, API
  responses are compressed and rows are slimmer: a 50-row page drops from
  67 KB to 5.2 KB on the wire, and a cold all-time History load from about
  380 ms to 20 ms. The UI also stops polling while the tab is hidden.
- **History gains bulk actions and an undo.** Multi-select several entries to
  delete or retry them, clear by status, and undo a deletion from the toast
  while it is still shown.
- **Downloads can be scheduled.** Time-of-day rules pause the queue, cap the
  speed or disable selected servers, evaluated in the process's local time and
  surviving restarts. A rule only lifts the pause it applied, so a manual
  pause or a disk-space hold is never swallowed.
- **All settings can be backed up to one TOML file and restored.** The export
  masks secrets by default and the import is validated, refusing files from a
  newer build or one with unknown keys.
- **New packages and integrations.** Linux AppImages (x86_64 and aarch64),
  Homebrew, Scoop and winget manifests, an opt-in unsigned macOS dmg dry run,
  and release binaries that embed their dependency data. The SABnzbd-compatible
  API now also accepts the key in an `X-Api-Key` header.

## Upgrade notes

- **Back up before upgrading:** your configuration directory (`config.toml`),
  the data directory holding the SQLite database, and the download directories.
  Database migrations run at startup; a fresh database is now migrated in a
  single transaction.
- **New `[par2]` settings.** `defer_volumes = true` holds recovery volumes
  until damage is seen; `trust_inflight_verify = true` accepts a PAR2 set as
  verified from the in-flight slice map when it covers every file. Set either
  to `false` for the previous behaviour of verifying from disk and fetching
  every volume.
- **History deletions are now restorable** from the undo toast rather than
  being immediately permanent.
- **WebDAV consumers:** history entries served over DAV no longer include the
  PAR2 volume fields. Native API consumers see no removals.
- **Scheduling defaults are unchanged.** Scheduling is opt-in (`[schedule]
  enabled = false`), and a speed cap of `0` now means unlimited.
- **Building from source requires Rust 1.95** (previously 1.88).
- **The macOS dmg is unsigned and not notarised.** It is an off-by-default dry
  run and is not attached to this release. If you build one, Gatekeeper blocks
  the first launch; open it once with Control-click → **Open**, or run
  `xattr -dr com.apple.quarantine /Applications/rustnzb.app`.
- **AppImages need FUSE.** Without it, run them with `--appimage-extract-and-run`.

## All changes

### Added

- **par2:** slice map built and verified while downloading, with per-job
  coverage that handles late indexes, restarts and obfuscated files
- **par2:** in-flight repair fold, driven from the download engine, with
  bounded disk-prefix fallback
- **par2:** recovery volumes held until damage is detected, and only enough
  fetched to cover it
- **par2:** parity-aware hopeless detection
- **par2:** `trust_inflight_verify` setting; verified recovery packets and
  bounded retention
- **queue:** damage ledger wired into the download path, with rows pruned for
  removed jobs and expired holes
- **api:** bulk delete and retry for history entries
- **ui:** History multi-select, bulk delete/retry and clear-by-status, with
  undo toasts for deletion and retry
- **schedule:** time-of-day pause, speed cap and server rotation
- **config:** back up and restore every setting as one TOML file
- **ui:** global keyboard shortcuts and a `?` help sheet
- **ui:** drop `.nzb` files or paste a URL anywhere to add a job
- **ui:** warn before leaving Settings with unsaved changes
- **ui:** PWA web manifest with icons and a theme colour
- **ui:** English i18n catalog and a locale switch
- **notify:** complete post-processing script environment and background alerts
- **sab:** accept the API key from an `X-Api-Key` header
- **api:** OpenAPI documentation for the native API
- **packaging:** Linux AppImages for x86_64 and aarch64, and an opt-in unsigned
  macOS dmg dry run
- **packaging:** Homebrew, Scoop and winget manifests
- **build:** embedded dependency data in release binaries

### Changed

- **perf (history):** list columns read from a side table; statistics,
  categories and page counts aggregated in SQLite over covering indexes
- **perf (http):** compressed API and SPA responses; detail-only fields left out
  of history list rows
- **perf (ui):** history polling skipped while hidden or still loading
- **perf (engine):** yEnc decode, file writes and repair-fold growth moved to
  the blocking pool so downloads no longer stall the async runtime
- **queue:** held PAR2 volumes excluded from queue size; history records the
  volumes actually fetched
- **ui:** Inter bundled locally, OS theme followed, async results announced to
  screen readers
- **webdav:** PAR2 volume fields removed from DAV history entries
- **schedule:** overlapping holds, windows and manual resumes kept independent;
  a window that opens during a disk hold stays paused after the hold lifts
- **toolchain:** Rust 1.95
- **docs:** full configuration reference, a SABnzbd migration guide, and README
  screenshots

### Fixed

- **schedule:** pause state is loaded without being written back at boot
- **schedule:** window bookkeeping is restored after a restart
- **config:** indexer keys stay out of a masked backup
- **api:** a status-wide history delete only accepts terminal statuses
- **ui:** fetch errors are surfaced with a Retry action instead of empty states
- **ui:** a file dropped on a queue row still reaches the page-wide drop
  handler, and shortcuts keep working while a toast is open
- **db:** a fresh database migrates in one transaction
