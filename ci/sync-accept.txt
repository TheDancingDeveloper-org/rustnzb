# Standalone-repo commits a sync may overwrite, reviewed one by one.
# One per line: <crate> <sha> <reason>. The sha is a prefix of the full commit
# id, at least 7 characters. Blank lines and #-comments are ignored.
#
# ci/tasks/sync-crate refuses to replace a standalone tree while a commit made
# there since the last sync changes a path the monorepo does not export
# byte-for-byte (docs/RELEASING.md). Listing a commit here records the decision
# that its change is superseded or already ported, so the sync goes ahead and
# names it in the log and the PR body. An entry is dead once the sync that
# overwrote it has merged (the last-sync anchor moves past it) and can then be
# removed.
